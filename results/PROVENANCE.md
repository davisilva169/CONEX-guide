# Provenance of reference results

The English reference figures were regenerated on 28 October 2026 with the localized macros, using real events from the reproduction script. They retain the physics settings of the guide validated on 25 October. No synthetic data are presented as CONEX output.

- Environment: Linux through WSL 2; ROOT 6.36.04, Python 3.13.17. Existing isolated tools and previously compiled CONEX were used; Anaconda installation was not repeated.
- Distribution: folder conex2r7.801, README 7.80, internal identifier 7801; Header Version 78.010002 and OutputVersion 2.51 have different roles.
- Models: high-energy model 5, SIBYLL 2.3e; low-energy UrQMD, LEModel 8, HiLowEgy 80 GeV. Fixed log10(E/eV)=17, zenith limits 0/0, azimuth 0, supplied SIBYLL defaults.
- first-profile.pdf: event 0, proton code 100, seed 314159, one event, 104 profile planes. Generated by macros/profile.C; deposit integrated over 103 intervals.
- primary-comparison.pdf and comparison-summary.csv: 12 proton events, seed 271828, and 12 iron-56 events, code 5600, seed 271829. Generated by macros/compare.C. Thirty bins spanning 0–1200 g/cm², width 40; no rejected values or underflow/overflow in these reference samples. Sample standard deviation uses n-1; standard error is s/sqrt(n). No Gaussian fit.
- The hybrid-method diagram is original conceptual artwork, not a data plot.

Only presentation figures and aggregate summaries are included. Event ROOT files and per-particle/per-event CSVs remain local.
